**Panel Heat** is a cover art studio that runs entirely in your browser. Load your own photos, arrange them across bold multi-panel poster layouts (Solo Shot, Split Duo, Triptych, Hero & Crew, Quad Grid and Five Star), drag and zoom each photo inside its panel, wash the whole cover in a Vice Sunset, Neon Nights, Golden Hour or Midnight Noir colour grade, and stamp it with heavy poster lettering — an editable title and tagline set in the bundled Anton display font. When it looks right, export a share-ready PNG in the common post sizes: 1080 × 1080, 1080 × 1350 or 1920 × 1080. Few steps from photo to post, and completely private: photos are read on your own machine and never uploaded anywhere.

Panel Heat is an original tool — its layouts, grades and lettering are its own design, with no artwork, logos or fonts taken from any game.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser

# to produce the entry output (app/ + screenshots/ + dossier.json) outside the grader:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
